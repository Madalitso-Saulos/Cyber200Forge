# Standards & Frameworks

These were not part of the original source material but are added as **[Recommended Additional Resources]** because they provide industry context for the practical skills built in this repository.

| Name | Description | Relevant To |
|---|---|---|
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | Industry-standard list of the most critical web application security risks. | [`02-web-exploitation-basics`](../challenges/02-web-exploitation-basics/README.md) |
| [OWASP Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Detailed methodology for testing web application security. | [`02-web-exploitation-basics`](../challenges/02-web-exploitation-basics/README.md), [`labs/lab-02-web-recon-and-intercept`](../labs/lab-02-web-recon-and-intercept/README.md) |
| [MITRE ATT&CK](https://attack.mitre.org/) | Knowledge base of adversary tactics and techniques based on real-world observations. | Reverse Engineering, Network Traffic Analysis stages |
| [NIST SP 800-61 Rev. 2](https://csrc.nist.gov/pubs/sp/800/61/r2/final) | Computer Security Incident Handling Guide — foundational for blue-team/incident response context. | [`labs/lab-03-memory-and-disk-forensics`](../labs/lab-03-memory-and-disk-forensics/README.md) |
| [NIST SP 800-86](https://csrc.nist.gov/pubs/sp/800/86/final) | Guide to Integrating Forensic Techniques into Incident Response. | [`04-digital-forensics-hidden-in-plain-sight`](../challenges/04-digital-forensics-hidden-in-plain-sight/README.md) |
| [CWE (Common Weakness Enumeration)](https://cwe.mitre.org/) | Community-developed list of common software and hardware weakness types. | [`07-reverse-engineering-crackme`](../challenges/07-reverse-engineering-crackme/README.md) |
| [CVE Program](https://www.cve.org/) | Reference system for publicly known cybersecurity vulnerabilities. | General reference |

These frameworks are optional reading — they provide the "why it matters professionally" context around the hands-on skills each challenge builds.
