## Beginner-Friendly

### OverTheWire
- **Category:** Wargame — Linux fundamentals
- **Description:** Series of wargames (starting with "Bandit") that teach Linux command-line skills essential for all other CTF categories.
- **Recommended level:** Beginner
- **Relevant challenges:** [`01-linux-foundations`](../challenges/01-linux-foundations/README.md)
- **Official URL:** https://overthewire.org/wargames/

### picoCTF / picoGym
- **Category:** Jeopardy CTF platform
- **Description:** Beginner-oriented, year-round CTF platform run by Carnegie Mellon University. picoGym offers a noncompetitive practice space using challenges from past competitions.
- **Recommended level:** Beginner
- **Relevant challenges:** All starter challenges
- **Official URL:** https://picoctf.org/

### TryHackMe
- **Category:** Guided training platform
- **Description:** Browser-accessible rooms with guided walkthroughs covering security concepts and CTF-style challenges.
- **Recommended level:** Beginner–Intermediate
- **Relevant challenges:** [`07-reverse-engineering-crackme`](../challenges/07-reverse-engineering-crackme/README.md) (Reversing ELF room)
- **Official URL:** https://tryhackme.com/

### Hacker101
- **Category:** Web-focused CTF
- **Description:** Collection of web-based CTF challenges from HackerOne, paired with free video lessons on web security.
- **Recommended level:** Beginner–Intermediate
- **Relevant challenges:** [`02-web-exploitation-basics`](../challenges/02-web-exploitation-basics/README.md)
- **Official URL:** https://www.hacker101.com/

### Root-Me
- **Category:** Jeopardy CTF platform
- **Description:** Large catalog of challenges spanning nearly every CTF category, sorted by difficulty.
- **Recommended level:** Beginner–Advanced
- **Relevant challenges:** All starter challenges
- **Official URL:** https://www.root-me.org/

### Vulnversity
- **Category:** Guided beginner room
- **Description:** Introductory penetration-testing walkthrough covering reconnaissance and basic exploitation.
- **Recommended level:** Beginner
- **Relevant challenges:** [`02-web-exploitation-basics`](../challenges/02-web-exploitation-basics/README.md)
- **Official URL:** [URL REQUIRES VERIFICATION]

### CryptoHack
- **Category:** Cryptography-focused CTF
- **Description:** Progressive cryptography challenges from basic encoding through advanced attacks.
- **Recommended level:** Beginner–Advanced
- **Relevant challenges:** [`03-cryptography-decode-the-cipher`](../challenges/03-cryptography-decode-the-cipher/README.md)
- **Official URL:** https://cryptohack.org/

## Advanced

### Hack The Box
- **Category:** Wargame / VM-based
- **Description:** Weekly-refreshed retired and active machines spanning all skill levels, popular for building a full attack-chain skillset.
- **Recommended level:** Intermediate–Advanced
- **Relevant challenges:** All starter challenges
- **Official URL:** https://www.hackthebox.com/

### VulnHub
- **Category:** VM-based practice
- **Description:** Large repository of downloadable, intentionally vulnerable VM images for offline practice.
- **Recommended level:** Intermediate–Advanced
- **Relevant challenges:** [`labs/lab-02-web-recon-and-intercept`](../labs/lab-02-web-recon-and-intercept/README.md), [`labs/lab-03-memory-and-disk-forensics`](../labs/lab-03-memory-and-disk-forensics/README.md)
- **Official URL:** https://www.vulnhub.com/

### Damn Vulnerable Web Application (DVWA)
- **Category:** Self-hosted web target
- **Description:** PHP/MySQL application with adjustable difficulty, intentionally vulnerable for practicing web attack classes.
- **Recommended level:** Beginner–Advanced
- **Relevant challenges:** [`02-web-exploitation-basics`](../challenges/02-web-exploitation-basics/README.md)
- **Official URL:** https://github.com/digininja/DVWA

### Crackmes.one
- **Category:** Reverse engineering wargame
- **Description:** Community-submitted reverse engineering challenges ("crackmes") across many architectures and difficulty ratings.
- **Recommended level:** Intermediate–Advanced
- **Relevant challenges:** [`07-reverse-engineering-crackme`](../challenges/07-reverse-engineering-crackme/README.md)
- **Official URL:** https://crackmes.one/

### Pwnable.kr / Pwnable.tw / Pwnable.xyz
- **Category:** Binary exploitation wargame
- **Description:** Progressive binary exploitation challenges focused on memory corruption and low-level exploitation.
- **Recommended level:** Advanced
- **Relevant challenges:** [`07-reverse-engineering-crackme`](../challenges/07-reverse-engineering-crackme/README.md)
- **Official URL:** https://pwnable.kr/ , https://pwnable.tw/ , https://pwnable.xyz/

### Microcorruption
- **Category:** Embedded security wargame
- **Description:** Simulated embedded-device CTF teaching assembly-level exploitation.
- **Recommended level:** Advanced
- **Relevant challenges:** [`07-reverse-engineering-crackme`](../challenges/07-reverse-engineering-crackme/README.md)
- **Official URL:** [URL REQUIRES VERIFICATION]
