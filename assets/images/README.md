# Assets / Images

Reserved for diagrams, screenshots, and illustrative images used across challenge and lab documentation. No images were required for the current starter content. When adding an image:

- Use descriptive, kebab-case filenames (e.g., `pcap-http-stream-example.png`).
- Reference it from Markdown using a relative path, e.g. `![description](../assets/images/filename.png)`.
- Do not include screenshots containing real personal data, real credentials, or identifiable third-party systems.
