# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — Initial Release

### Added

- Initial repository structure (`docs/`, `challenges/`, `labs/`, `resources/`, `templates/`, `scripts/`, `assets/`).
- Root documentation: `README.md`, `LICENSE`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `.gitignore`.
- Seven starter challenges spanning Linux foundations, web exploitation, cryptography, digital forensics, steganography, network traffic analysis, and reverse engineering.
- Three starter labs: Linux CLI mastery, web reconnaissance and interception, and memory/disk forensics.
- Resource library covering tools, books, courses, documentation, standards/frameworks, practice platforms, and cheat sheets.
- Reusable templates for challenges, labs, and lab reports.
- Learning path, prerequisites, lab environment guidelines, and safety/ethics documentation.

### Notes

- Content is derived primarily from an internal CTF onboarding guide and beginner's guide, supplemented by the community-maintained Awesome CTF resource list. Additions beyond the original source material are marked as **Recommended Additional Resources** in `docs/resources.md`.
- Some third-party URLs are flagged `[URL REQUIRES VERIFICATION]` where they could not be independently confirmed at time of writing.
