# Objectives

After completing this challenge, you should be able to:

1. Open and triage a PCAP file in Wireshark.
2. Apply display filters to narrow down traffic of interest (e.g., `http`, `ftp`, `dns`).
3. Use "Follow TCP Stream" to reconstruct a plaintext conversation.
4. Export an object (e.g., a transferred file) directly from captured HTTP traffic.
5. Explain why unencrypted protocols (HTTP, FTP, Telnet) expose credentials and data to anyone who can capture the traffic.
