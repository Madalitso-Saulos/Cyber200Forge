# Objectives

After completing this challenge, you should be able to:

1. Identify a file's true type using its file signature (magic bytes), rather than trusting its extension.
2. Use `file` and a hex editor to detect a mismatched file extension.
3. Use `strings` to locate plaintext fragments inside a binary file.
4. Use `exiftool` to extract metadata that reveals hidden information.
5. Use `binwalk` to detect and extract a file embedded inside another file.
