# Objectives

After completing this challenge, you should be able to:

1. Identify a binary's file type and architecture using `file`.
2. Extract readable strings from a compiled binary to form hypotheses before disassembling.
3. Load a binary into Ghidra and locate the function responsible for validating input.
4. Read decompiled pseudocode well enough to identify a hardcoded comparison value.
5. Use GDB to dynamically confirm your static-analysis hypothesis by setting a breakpoint and inspecting a register/variable at runtime.
