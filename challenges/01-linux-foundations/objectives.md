# Objectives

After completing this challenge, you should be able to:

1. Navigate the Linux filesystem confidently (`cd`, `ls`, `pwd`, absolute vs. relative paths).
2. Read and interpret Linux file permissions, and change them with `chmod`/`chown`.
3. Use `grep`, `find`, and `awk` to locate specific text and files.
4. Use pipes and redirection to chain commands together.
5. Extract files from common archive formats (`zip`, `tar`, `gzip`).
6. Explain, at a basic level, why Linux proficiency is "non-negotiable" for every other CTF category.
