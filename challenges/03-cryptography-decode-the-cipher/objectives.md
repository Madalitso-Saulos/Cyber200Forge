# Objectives

After completing this challenge, you should be able to:

1. Recognize Base64 encoding by its alphanumeric charset and `=` padding.
2. Recognize ASCII-encoded hexadecimal by its `0-9`/`A-F` charset.
3. Decode a layered encoding (e.g., Base64 wrapped around hex wrapped around a Caesar/ROT cipher) using CyberChef.
4. Explain the difference between *encoding* (reversible, no key) and *encryption* (requires a key).
5. Recover a XOR-encrypted string when given the key.
