# Scripts

This directory is reserved for helper scripts that support challenges and labs (e.g., environment setup scripts, sample-file generators).

No scripts were required for the current set of starter challenges and labs, so this directory currently contains only this placeholder. When contributing a script:

- Keep it self-contained and well-commented.
- State clearly at the top of the script which challenge/lab it supports.
- Never include real credentials, real malware, or anything that could cause harm outside an isolated lab — see [`../docs/safety-and-ethics.md`](../docs/safety-and-ethics.md).
- Add a short usage note to this README describing what the script does and how to run it.
